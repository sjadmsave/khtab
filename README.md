# خطب الجمعة

تطبيق ويب عربي قابل للتثبيت (PWA) لقراءة والاستماع إلى 45 خطبة جمعة.

**تنبيه:** ملفات الصوت غير مضمّنة داخل هذا المستودع؛ يستخدم التطبيق روابط الصوت الخارجية كما كانت في المشروع الأصلي.

يحتوي المشروع على تحسينات للتنقل، واستعادة موضع القراءة، والبحث، والأداء، وإمكانية الوصول.
